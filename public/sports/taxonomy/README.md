# Sports taxonomy icons

Static taxonomy icons collected from the Future and Polymarket sports navigation.

- Use these assets by URL, for example `/sports/taxonomy/soccer.svg`.
- Prefer SVG files where the source provides vector artwork.
- Keep raster brand marks in their extracted PNG or JPEG format.
- `baseball.svg` is shared with MLB, and `combat.svg` is shared with UFC.
- Country and region icons used by league taxonomies live in `countries/`.
- League artwork extracted from Polymarket's inline sports taxonomy lives in `polymarket/`.
- Generic icons reused as secondary taxonomy placeholders are intentionally excluded.
